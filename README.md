## Проект для онлайн-обучения (Django с Docker Compose) ##
Этот проект использует Docker Compose для запуска всех необходимых сервисов: Django, 
PostgreSQL, Redis, Celery и Celery Beat.

## Установка:

1. Клонируйте проект в свой репозиторий по ссылке:

```
git clone github.com/DashulyaE/homework_modul8
```
2. Создайте файл .env в корне проекта, заполнив его на основании примера 
из файла .env.example
3. Постройте и запустите контейнеры командой:
```
docker-compose up -d --build
```
4. Проверьте, что все сервисы запущены:
```
docker ps
```

## Проверка работоспособности ##
1. Основной сайт:
- Откройте браузер и перейдите по адресу:
http://localhost:8000
2. Админка Django:
- http://localhost:8000/admin
Войдите с логином и паролем, созданными при миграциях.
3. Логи сервисов:
- Для просмотра логов используйте:
```
docker-compose logs
```
или для конкретного сервиса:
```
docker logs <имя_контейнера>
```

## Остановка проекта ##
Чтобы остановить и удалить все контейнеры, выполните:
```
docker-compose down
```

## Дополнительные команды ##
1. Пересобрать и запустить заново:
```
docker-compose up -d --build
```

2. Запустить миграции и создать суперпользователя:
```
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser
```
Эти команды нужны для настройки базы данных и админки Django.
### Важно! ###
Когда запускать:
- После первого запуска контейнеров, чтобы подготовить базу.
- При обновлении моделей или миграций.

Если у вас уже есть настроенная база и созданный суперпользователь, повторять эти команды не обязательно.

3. Настройка удаленного сервера
 - Откройте терминал и выполните команду для обновления списка пакетов:
```
sudo apt update
```
 - Затем выполните команду для обновления всех установленных пакетов до их последних версий:
```
sudo apt upgrade
```
4. Установка Docker 
Чтобы установить Docker, воспользуйтесь инструкцией по установке с официального сайта: https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository.
5. Настройте файрвол
### Шаги для запуска workflow и деплоя приложения ###
1. В вашей репозитории на github перейдите в Settings > Secrets.
2. Добавьте секреты:
- SSH_KEY — приватный SSH-ключ для доступа к серверу
- SERVER_IP - IP-адрес сервера
- SSH_USER — пользователь для SSH
- DEPLOY_DIR — путь к директории проекта на сервере
- NAME, USER, PASSWORD, HOST, PORT — параметры базы данных
SECRET_KEY
— секретный ключ Django
3. Не забудьте сгенерировать ssh ключ (публичный и приватный) для автоматических сервисов
4. Запуск workflow
- После пуша изменений GitHub автоматически запустит workflow.
